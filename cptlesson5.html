Lesson 5: Surgery

Learn how the CPT Surgery section is organized and review important concepts used when coding surgical procedures.

The CPT Surgery Section

The CPT Surgery section contains codes used to report many surgical procedures performed by healthcare professionals.

Surgery codes are generally organized according to the body system or anatomical area involved.

Surgery Subsections

The Surgery section contains multiple subsections based on body systems and types of procedures.

Examples include:

  • Integumentary System
  • Musculoskeletal System
  • Respiratory System
  • Cardiovascular System
  • Digestive System
  • Urinary System
  • Male and Female Genital Systems
  • Nervous System
  • Eye and Ocular Adnexa
  • Auditory System

Read the Operative Report

Accurate surgery coding requires careful review of the provider's documentation.

The operative report can contain important details about the procedure performed, anatomical location, surgical approach, and other information needed for code selection.

Remember: Code the procedure supported by the documentation. Never choose a surgical code based only on the procedure title without reviewing the complete documentation.

Separate Procedure

Some CPT codes include the designation "separate procedure."

This designation can affect whether a procedure is separately reportable when performed with another related procedure.

Coders should review CPT guidelines and applicable bundling rules before reporting the service separately.

Surgical Packages

Certain services related to a surgical procedure may be included in the surgical package rather than separately reported.

Coders should review CPT guidance and payer rules to determine which services are included.

Modifiers

A CPT modifier may sometimes be needed to provide additional information about a surgical service.

Modifiers do not automatically change the basic procedure performed. Instead, they provide additional information about the circumstances of the service.

Important: Never add a modifier simply to obtain payment. The documentation and applicable coding rules must support its use.

Example

A provider performs a surgical procedure.

Before selecting the CPT code, the coder should review the operative report, identify the procedure and anatomical location, and then verify the code and applicable instructions in the CPT code set.

Quick Check

What document commonly provides detailed information about a surgical procedure?

Answer: The operative report.

Lesson 5 Goals

By the end of this lesson, you should be able to:

  • Explain the basic purpose of the CPT Surgery section.
  • Recognize that surgery codes are organized into subsections.
  • Understand why the operative report is important.
  • Recognize the meaning of "separate procedure."
  • Understand the basic concept of a surgical package.
  • Understand why modifiers must be supported by documentation.
