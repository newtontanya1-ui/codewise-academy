Lesson 2: CPT Code Structure and Categories

Learn how CPT codes are structured and understand the three main categories of CPT codes.

Understanding CPT Code Structure

CPT codes are used to identify medical services and procedures performed by healthcare professionals.

Category I CPT codes contain five numeric characters.

Example:

A Category I CPT code may look like:

99213

The Three CPT Categories

CPT codes are divided into three categories:

  • Category I
  • Category II
  • Category III

Each category has a different purpose and a different code format.

Category I Codes

Category I codes are the codes most commonly used to report medical services and procedures.

They are generally five-digit numeric codes.

Category I codes are organized into six major sections:

  • Evaluation and Management
  • Anesthesia
  • Surgery
  • Radiology
  • Pathology and Laboratory
  • Medicine

Category II Codes

Category II codes are supplemental tracking codes that may be used for performance measurement.

These codes contain four digits followed by the letter F.

Example format:

1234F

Remember: Category II codes are supplemental codes and are different from the Category I codes used to report many procedures and services.

Category III Codes

Category III codes are temporary codes used for emerging technologies, services, procedures, and service paradigms.

Category III codes contain four digits followed by the letter T.

Example format:

0123T

Why Do the Categories Matter?

Recognizing the category helps a coder understand the basic purpose and format of a CPT code.

Coders should carefully review the applicable CPT instructions and code descriptions before assigning a code.

Quick Check

You see a CPT code containing four digits followed by the letter T.

Which CPT category is it?

Answer: It is a Category III CPT code.

Lesson 2 Goals

By the end of this lesson, you should be able to:

  • Recognize the basic structure of Category I CPT codes.
  • Name the three CPT categories.
  • Explain the basic purpose of Category I codes.
  • Recognize the Category II code format.
  • Recognize the Category III code format.
  • Name the six major Category I sections.
