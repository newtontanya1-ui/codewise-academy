Lesson 4: Conventions and Coding Guidelines

Learn the conventions, instructional notes, and guidelines used to correctly assign ICD-10-CM diagnosis codes.

What Are ICD-10-CM Conventions?

ICD-10-CM conventions are rules and instructions built into the classification system.

Coders use these conventions along with the Official Guidelines for Coding and Reporting when assigning diagnosis codes.

Remember: Always read the instructional notes associated with a category, subcategory, or code before making a final code selection.

Includes Notes

An Includes note gives examples or additional information about conditions included within a category.

Tip: Includes notes help the coder understand what conditions are classified within that category.

Excludes1

An Excludes1 note generally means that the excluded condition should not be coded together with the code above the note.

The conditions are considered separate for purposes of that instruction.

Excludes2

An Excludes2 note means that the excluded condition is not included in the code above the note.

However, when the patient has both conditions, it may be appropriate to report both codes.

Code First

A "code first" instruction tells the coder that another underlying condition should be sequenced before the condition containing the instruction.

Important: Code sequencing matters. Always follow instructional notes and applicable coding guidelines.

Use Additional Code

A "use additional code" instruction tells the coder that another code may be needed to provide additional information about the patient's condition.

Code Also

A "code also" note indicates that two codes may be required to completely describe a condition.

Sequencing depends on the circumstances of the encounter and applicable coding guidelines.

Official Coding Guidelines

The ICD-10-CM Official Guidelines for Coding and Reporting provide instructions for assigning and sequencing diagnosis codes.

Coders should use the Alphabetic Index, Tabular List, instructional notes, and official guidelines together when determining the correct code.

Never code from the Alphabetic Index alone. After locating a possible code in the Index, verify the code in the Tabular List and follow all applicable notes and instructions.

Lesson 4 Goals

By the end of this lesson, you should be able to:

  • Explain what ICD-10-CM conventions are.
  • Recognize Includes notes.
  • Understand Excludes1 and Excludes2 notes.
  • Recognize Code First instructions.
  • Understand Use Additional Code instructions.
  • Recognize Code Also notes.
  • Understand why official coding guidelines are important.
