Lesson 10: HCPCS Coding Practice and Review

Review the major concepts from HCPCS Level II Foundations and practice what you have learned.

Final HCPCS Review

HCPCS Level II coding is used to report many healthcare supplies, products, medications, equipment, and services.

Accurate coding requires careful review of documentation and the complete HCPCS code description.

Remember: Never select a code based only on the first letter or a partial description. Always verify the complete current code and applicable guidance.

Practice Question 1

What does HCPCS stand for?

Check Answer

Healthcare Common Procedure Coding System.

Practice Question 2

How are HCPCS Level II codes generally formatted?

Check Answer

They are generally five characters: one letter followed by four numbers.

Practice Question 3

What does DME stand for?

Check Answer

Durable Medical Equipment.

Practice Question 4

Which HCPCS Level II letter range contains many drug codes?

Check Answer

The J-code range contains many drug codes.

Practice Question 5

Which HCPCS Level II letter range contains many orthotic and prosthetic codes?

Check Answer

The L-code range.

Practice Question 6

Which modifier identifies the right side when applicable?

Check Answer

RT.

Practice Question 7

Which modifier identifies the left side when applicable?

Check Answer

LT.

Practice Question 8

A HCPCS code represents 10 mg per unit. The patient receives 40 mg. How many units would be reported in this simplified example?

Check Answer

40 mg ÷ 10 mg = 4 units.

Practice Question 9

Does having a valid HCPCS code automatically guarantee insurance coverage?

Check Answer

No. Correct coding does not automatically guarantee coverage or payment.

Practice Question 10

What should support the HCPCS Level II code and units reported?

Check Answer

The medical documentation and applicable coding requirements.
