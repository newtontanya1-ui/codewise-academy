Lesson 7: 7th Characters and Placeholders

Learn how ICD-10-CM uses 7th characters and the placeholder X to provide additional information about certain diagnoses.

What Is a 7th Character?

Some ICD-10-CM categories require a 7th character to provide additional information about the condition or encounter.

When a 7th character is required, it must appear in the seventh position for the code to be complete.

Remember: Always check the Tabular List to determine whether a 7th character is required and which character is appropriate.

Common 7th Characters for Injuries

Many injury codes use 7th characters to describe the type of encounter.

  • A – Initial encounter
  • D – Subsequent encounter
  • S – Sequela

Initial Encounter

The 7th character A is generally used while the patient is receiving active treatment for the condition.

Example: A patient receiving active treatment for a new injury may require a code ending with the 7th character A.

Subsequent Encounter

The 7th character D is generally used after active treatment has been completed and the patient is receiving routine care during the healing or recovery period.

Sequela

The 7th character S is used for a residual effect that remains after the acute phase of an injury or condition has ended.

Sequela coding has special sequencing rules, so coders should always follow the applicable ICD-10-CM guidelines.

What Is a Placeholder?

ICD-10-CM sometimes uses the letter X as a placeholder.

The placeholder keeps characters in their required positions and allows a required 7th character to appear in the seventh position.

Important: When a placeholder X is required, it must be included for the ICD-10-CM code to be valid.

Quick Check

An ICD-10-CM code requires a 7th character, but the code does not contain enough characters to place it in the seventh position. What may be needed?

Answer: The placeholder X may be required to fill the empty position or positions before the 7th character.

Lesson 7 Goals

By the end of this lesson, you should be able to:

  • Explain the purpose of a 7th character.
  • Recognize A, D, and S encounter characters.
  • Understand the basic meaning of initial and subsequent encounters.
  • Explain what sequela means.
  • Explain why the placeholder X is used.
