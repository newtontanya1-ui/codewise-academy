Lesson 6: Laterality

Learn how ICD-10-CM codes identify the right side, left side, bilateral conditions, and unspecified side.

What Is Laterality?

Laterality means identifying which side of the body is affected by a disease, injury, or other condition.

Many ICD-10-CM codes provide different code choices depending on the side of the body involved.

Right and Left

When ICD-10-CM provides separate codes for the right and left sides, the coder should select the code that matches the provider's documentation.

Example: If the provider documents an injury to the patient's left knee, the coder should select the ICD-10-CM code representing the left knee when one is available.

Bilateral Conditions

Bilateral means that the condition affects both sides of the body.

If ICD-10-CM provides a bilateral code, that code may be used when the documentation supports it.

If a bilateral code is not available, separate right and left codes may be required when appropriate.

Unspecified Side

An unspecified-side code may be appropriate when the provider's documentation does not identify which side of the body is affected.

Remember: Never guess the patient's laterality. Select a more specific right or left code only when the documentation supports it.

Why Laterality Matters

Correct laterality makes diagnosis coding more accurate and gives a clearer description of the patient's condition.

Coders should carefully review the medical record for documentation identifying the affected side.

Quick Check

The provider documents arthritis of the patient's right knee. ICD-10-CM provides separate right, left, and unspecified codes.

Which option should you choose?

Answer: Choose the code for the right knee because the provider documented the affected side.

Lesson 6 Goals

By the end of this lesson, you should be able to:

  • Explain what laterality means.
  • Recognize right and left code choices.
  • Understand what bilateral means.
  • Understand when an unspecified-side code may be used.
  • Explain why coders should never guess laterality.
