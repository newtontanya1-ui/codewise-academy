ICD-10-CM Basics

  • ICD-10-CM is used to report diagnoses and health conditions.
  • Codes can contain letters and numbers.
  • Codes may contain between 3 and 7 characters.
  • Always code to the highest level of specificity available.

Important Coding Rules

  • Start your code search in the Alphabetic Index.
  • Always verify the code in the Tabular List.
  • Follow all Includes, Excludes1, Excludes2, and Code First notes.
  • Use additional codes when instructed.
  • Do not code uncertain diagnoses in the outpatient setting.

7th Characters

  • A = Initial encounter
  • D = Subsequent encounter
  • S = Sequela

Helpful Reminders

  • Read the entire medical record before choosing a code.
  • Never choose a code from the Alphabetic Index alone.
  • Pay close attention to laterality: right, left, or bilateral.
  • Look for combination codes before assigning multiple codes.
  • Check instructional notes before finalizing your answer.
