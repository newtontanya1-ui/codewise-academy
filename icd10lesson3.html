Lesson 3: alphabetic index & tabular list

Learn how to locate a condition in alphabetic index and verify the code in the tabular list.

What is the alphabetic index?

coders usually begin by identifying the main term in the provider's diagnosis and locating that term in the alphabetic index.

the alphabetic index list diagnoses and conditions alphabetically so coders can find a possible icd-10-cm code to verify.

What is the tabular list?

after finding a possiable code in the alphabetic index, the coder must verify that code in the tabular list.

the tabular list includes important notes, exclusions, additional character requirments, and other instructions needed to choose the correct icd-10-cm code.

important: never assign an icd-10-cm code using only the alphabetic index. always verify the code in the tabular list.

the two-step coding process

step 1: find the diagnosis or condition in the alphabetic index.

step 2: verify the suggested code in the tabular list.

this two-step process helps make sure the code is complete, accurate, and supported by provider's documentation.

Lesson Goal

by the end of this lesson,you should be able to:

  • explain what the alphabetic index is used for.
  • explain why codes must be verified in the tabular list.
  • use the two step process to locate and verify an icd-10-cm code.
