Lesson 10: ICD-10-CM Coding Practice

Put together what you have learned throughout the ICD-10-CM Foundations course.

Before You Begin

Accurate diagnosis coding requires more than simply finding a code that looks correct.

Coders must review the provider's documentation, locate the diagnosis in the Alphabetic Index, verify the code in the Tabular List, and follow all applicable instructions and guidelines.

Remember: Never guess information that is not supported by the medical record.

Practice Question 1

The provider documents Type 2 diabetes mellitus without complications.

What information should you verify before assigning the final ICD-10-CM code?

Check Answer

Locate the diagnosis in the Alphabetic Index, then verify the code in the Tabular List and review all applicable notes and instructions.

Practice Question 2

A provider documents an injury to the patient's left ankle.

What detail is especially important when selecting the code?

Check Answer

Laterality is important. When ICD-10-CM provides separate codes for the right and left sides, select the left-side code supported by the documentation.

Practice Question 3

An injury code requires a 7th character, but the code does not have enough characters to place the required character in the seventh position.

What may be needed?

Check Answer

One or more placeholder X characters may be required so that the 7th character appears in the correct position.

Practice Question 4

You locate a possible diagnosis code in the Alphabetic Index.

What should you do next?

Check Answer

Verify the code in the Tabular List and review all applicable instructional notes before assigning the final code.

Practice Question 5

An outpatient provider documents a diagnosis as "suspected" but does not confirm the condition.

Should you automatically code the suspected diagnosis as confirmed?

Check Answer

No. In the outpatient setting, uncertain diagnoses are generally not coded as confirmed. Code to the highest degree of certainty known for the encounter.
