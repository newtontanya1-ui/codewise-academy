Lesson 8: Combination Codes

Learn how one ICD-10-CM code can sometimes represent multiple parts of a patient's diagnosis.

What Is a Combination Code?

A combination code is a single ICD-10-CM code used to classify two diagnoses, a diagnosis with a manifestation, or a diagnosis with an associated complication.

When an appropriate combination code fully describes the documented condition, separate codes may not be needed.

Why Are Combination Codes Important?

Combination codes allow coders to report related conditions accurately without assigning unnecessary separate codes.

Remember: Always review the Alphabetic Index and Tabular List to determine whether a combination code is available.

Diagnosis With a Complication

Some combination codes identify both a disease and a complication associated with that disease.

Example: Certain diabetes codes identify both the type of diabetes and a documented complication in one code.

Diagnosis With a Manifestation

A manifestation is a condition that develops as a result of another underlying disease.

ICD-10-CM may provide special instructions for coding the underlying condition and its manifestation.

Read the Documentation Carefully

A coder should never assume that two conditions are related unless the classification or provider's documentation supports the relationship.

Always follow ICD-10-CM conventions, instructional notes, and official coding guidelines.

Quick Check

You find an ICD-10-CM combination code that fully describes a documented diagnosis and its complication. What should you do?

Answer: Use the appropriate combination code when it fully identifies the documented conditions and coding guidelines support its use.

Lesson 8 Goals

By the end of this lesson, you should be able to:

  • Explain what a combination code is.
  • Recognize when one code may describe multiple conditions.
  • Understand the basic meaning of a manifestation.
  • Recognize combination codes involving complications.
  • Understand why documentation and coding guidelines matter.
