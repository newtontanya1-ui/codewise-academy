Lesson 6: Radiology

Learn how CPT codes are used to report diagnostic imaging and other radiology services.

The CPT Radiology Section

The CPT Radiology section contains codes for many diagnostic imaging and radiology services.

These services may be used to help healthcare providers diagnose, monitor, and treat patients.

Types of Radiology Services

The Radiology section includes different types of imaging and related services.

Examples include:

  • X-rays
  • Computed tomography (CT)
  • Magnetic resonance imaging (MRI)
  • Ultrasound
  • Nuclear medicine
  • Radiation oncology services

Professional and Technical Components

Some radiology services may include both a professional component and a technical component.

The professional component generally involves the physician's interpretation and report.

The technical component generally involves items such as equipment, supplies, and technical staff associated with performing the service.

Remember: Coders should determine what portion of the service was actually provided and follow applicable CPT and payer guidance.

Modifiers 26 and TC

In appropriate circumstances, modifiers may be used to identify components of certain services.

  • Modifier 26 identifies the professional component when applicable.
  • Modifier TC identifies the technical component when applicable.
Important: Not every radiology code is handled the same way. Always verify whether component reporting applies to the specific service.

Number of Views

Some radiology code descriptions distinguish services based on the number of views performed.

The coder should review the documentation carefully and select the code that accurately represents the documented service.

Example:

If a radiology code family contains different choices based on the number of views, the coder should use the documentation to determine the appropriate code.

Contrast Material

Some imaging procedures may be performed with contrast, without contrast, or both without and with contrast.

When the CPT code descriptions distinguish among these services, the documentation must support the code selected.

Documentation Matters

Accurate radiology coding requires clear documentation of the service performed.

Important details may include the anatomical area, type of imaging, number of views when applicable, use of contrast, and whether an interpretation and report were performed.

Quick Check

Which modifier may identify the professional component of an applicable radiology service?

Answer: Modifier 26.

Lesson 6 Goals

By the end of this lesson, you should be able to:

  • Explain the basic purpose of the CPT Radiology section.
  • Recognize common types of diagnostic imaging.
  • Understand professional and technical components.
  • Recognize modifiers 26 and TC.
  • Understand why the number of views may matter.
  • Recognize the importance of contrast documentation.
  • Explain why complete radiology documentation is important.
