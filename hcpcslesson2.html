Lesson 2: HCPCS Code Structure

Learn how HCPCS Level II codes are structured and how letters and numbers are used to identify healthcare items and services.

HCPCS Level II Code Format

HCPCS Level II codes are five characters long.

A HCPCS Level II code generally begins with one letter followed by four numbers.

Example format:

A1234

The first character is a letter and the remaining four characters are numbers.

Why Does the First Letter Matter?

The beginning letter helps organize HCPCS Level II codes into groups.

Different letter ranges may represent different types of supplies, equipment, drugs, or services.

Remember: The first letter can help you locate a code, but you must still verify the complete code description before reporting it.

Examples of HCPCS Code Groups

HCPCS Level II includes many different code groups. Examples can include:

  • A codes — certain transportation services and medical or surgical supplies
  • E codes — durable medical equipment
  • J codes — many drugs administered other than by oral method
  • L codes — certain orthotic and prosthetic procedures and devices

Read the Full Code Description

Coders should never select a HCPCS Level II code based only on the first letter.

The complete description may contain important information about the item, dosage, quantity, size, type, or service being reported.

Important: Always verify that the documentation supports the exact HCPCS Level II code selected.

Code Descriptions and Units

Some HCPCS Level II code descriptions identify a specific amount or quantity.

This is especially important when reporting certain drugs and supplies.

If a HCPCS code represents a specific amount of a product, the coder may need to calculate the correct number of units based on the amount actually provided.

Documentation Matters

The medical record should support the item, supply, medication, equipment, or service being reported.

Depending on the code, important documentation may include:

  • Type of item or service
  • Quantity provided
  • Dosage when applicable
  • Size or type of equipment
  • Reason the item or service was provided

Quick Check

How many characters are in a standard HCPCS Level II code?

Answer: Five characters — generally one letter followed by four numbers.

Lesson 2 Goals

By the end of this lesson, you should be able to:

  • Recognize the basic HCPCS Level II code format.
  • Understand why the first letter is important.
  • Recognize examples of HCPCS code groups.
  • Understand why the full code description must be reviewed.
  • Recognize that quantity and units may affect reporting.
  • Explain why documentation is important.
