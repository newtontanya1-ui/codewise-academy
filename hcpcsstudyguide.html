HCPCS Basics

  • HCPCS stands for Healthcare Common Procedure Coding System.
  • HCPCS Level II codes are used for supplies, equipment, medications, and services not included in CPT.
  • HCPCS Level II codes usually contain 1 letter followed by 4 numbers.
  • HCPCS Level II is maintained by the Centers for Medicare & Medicaid Services.

Common HCPCS Code Groups

  • A Codes: Transportation services and medical supplies.
  • E Codes: Durable medical equipment.
  • J Codes: Drugs administered other than by oral method.
  • L Codes: Orthotic and prosthetic procedures and devices.
  • Q Codes: Temporary codes assigned by CMS.

HCPCS Modifiers

  • Modifiers give additional information about a service, item, or procedure.
  • LT: Left side.
  • RT: Right side.
  • GA: Waiver of liability statement issued as required by payer policy.
  • GY: Item or service statutorily excluded or does not meet the definition of a Medicare benefit.

Units and Drug Coding

  • Always check the code description for the amount represented by one billing unit.
  • Compare the amount given to the patient with the amount listed in the HCPCS code description.
  • Calculate the correct number of units before submitting the claim.
  • Pay close attention to milligrams, milliliters, and dosage amounts.

Helpful HCPCS Coding Tips

  • Use the HCPCS Index to begin your search.
  • Verify the full code description before selecting the code.
  • Check whether a modifier is required.
  • Make sure the correct number of units is reported.
  • Review payer guidelines because coverage rules may vary.
  • Watch for temporary codes and annual code updates.
