Lesson 10: CPT Coding Practice and Review

Review the major concepts from CPT Foundations and practice applying what you have learned.

Before You Begin

Accurate CPT coding requires careful review of the service or procedure documented in the patient's medical record.

Coders should verify the complete CPT code description and review applicable guidelines, notes, and modifier requirements.

Remember: Never select a CPT code based only on a code description that appears close to the service. Review the complete documentation and applicable coding instructions.

Practice Question 1

What does CPT stand for?

Check Answer

Current Procedural Terminology.

Practice Question 2

Which major CPT section contains codes for many office and other patient visits?

Check Answer

Evaluation and Management, commonly called E/M.

Practice Question 3

What does MDM stand for in E/M coding?

Check Answer

Medical Decision Making.

Practice Question 4

Which CPT section contains codes for X-rays, CT scans, MRI, and other diagnostic imaging services?

Check Answer

The Radiology section.

Practice Question 5

Which modifier identifies the professional component of certain services when applicable?

Check Answer

Modifier 26.

Practice Question 6

Which modifier identifies the technical component of certain services when applicable?

Check Answer

Modifier TC.

Practice Question 7

What type of document commonly provides detailed information about a surgical procedure?

Check Answer

The operative report.

Practice Question 8

Should a coder add a modifier simply to increase reimbursement?

Check Answer

No. Modifier use must be supported by the documentation and applicable coding rules.
